# Воспроизведение исследования

Экспериментальная часть закрыта. Аудит проверяет сохранённые результаты; он не обучает модели и не меняет настройки. Raw-данные, checkpoints и промежуточные прогнозы хранятся локально и не входят в Git.

## Полное повторение исходной серии

Команды ниже заново готовят данные, обучают baseline и reward model, проводят RL-пилот и оценивают его. Выполняйте их в отдельном клоне с пустыми `data/` и `outputs/`: шаги `cp` заменяют агрегированные JSON в `experiments/`. Результаты исходного запуска от этого не меняются.

Использовалась Python 3.14.7; исходная среда закреплена в `requirements-lock.txt`. Для серий с CatBoost используйте полный [ranking lock](requirements-ranking-lock.txt), который включает те же базовые версии и CatBoost. Поздние серии также требуют checkpoints и результатов предыдущих этапов.

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
mkdir -p data/raw
curl -L --fail --output data/raw/yambda-50m-multi_event.parquet https://huggingface.co/datasets/yandex/yambda/resolve/main/flat/50m/multi_event.parquet
python -m recsys_rl prepare data/raw/yambda-50m-multi_event.parquet
python -m recsys_rl tune --device auto
cp outputs/small-tuning-v1/result.json experiments/small-tuning-result.json
python -m recsys_rl reward-prepare data/raw/yambda-50m-multi_event.parquet
python -m recsys_rl reward --device auto
cp outputs/reward-v1/summary.json experiments/reward-result.json
python -m recsys_rl reward-signal --device auto
cp outputs/reward-signal-v1/result.json experiments/reward-signal-result.json
python -m recsys_rl rl --device auto --prepare-only
python -m recsys_rl rl --device auto --resume
python -m recsys_rl rl-audit --device auto
cp outputs/policy-rl-pilot-v1/result.json experiments/rl-pilot-result.json
```

Перед final evaluation нужно заранее записать выбранный по validation checkpoint. В исходном запуске это raw-kl, seed 42. После создания собственного `rl-pilot-result.json` обновите его SHA в локальном execution manifest:

```bash
python - <<'PY'
from pathlib import Path
from recsys_rl.data import sha256, write_json
write_json(Path('experiments/rl-pilot-execution.json'), {
    'result_sha256': sha256(Path('experiments/rl-pilot-result.json')),
    'scope': 'Local reproduction; process accounting not collected.'
})
PY
python -m recsys_rl.final_evaluation --device auto
python -m recsys_rl.final_evaluation --device auto --audit
```

Это базовая цепочка, а не одна команда для повторения всей истории: поздние серии используют собственные протоколы, конфигурации и входные checkpoints. Порядок этапов и результаты см. в [README](README.md); условия каждого запуска — в соответствующем файле `experiments/*-protocol.md`.
