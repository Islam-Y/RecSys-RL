# Смешанная цель RL и next-item

## 1. Гипотеза и результат отбора

Проверена гипотеза: next-item loss во время RL уменьшит потерю релевантности. **Смешанный checkpoint не принят:** три варианта потеряли 3.19-3.60% validation NDCG при допуске 1%. Первая серия и её PDF сохранены.

Код, [протокол](experiments/mixed-objective-protocol.md) и [конфигурация](configs/mixed-objective.json) зафиксированы до подготовки новой выборки и обучения: `101920acd117358b0105980bdcb62a85cb1a473d`.

Цель: `L = -w_reward*E_pi[p] + beta*KL(pi||pi_ref) + gamma*CE`. Уникальные next-item цели усредняются внутри запроса. Все варианты начинают с одного reference seed 42, эпоха 26; используют прежние 4 000 поздних train-историй и frozen reward-кэш.

Пять эпох, последняя эпоха без early stopping; AdamW learning rate 0.00005, batch 64, weight decay 0, clip norm 1, dropout выключен. Reward model и калибровка не меняются. Идея смешивания мотивирована [Ouyang et al., PPO-ptx](https://arxiv.org/html/2203.02155v1); её перенос в рекомендации проверяется отдельно.

| Вариант, seed 42 | gamma | beta | NDCG@10 | Hybrid reward |
|---|---:|---:|---:|---:|
| Reference | - | - | 0.10275 | 0.64978 |
| RL-only | 0 | 0.1 | 0.09925 | 0.66220 |
| Strong KL | 0 | 1 | 0.10271 | 0.65148 |
| Next-item-only | 1 | 0 | 0.09557 | 0.64952 |
| Mixed-001 | 0.001 | 0.1 | 0.09905 | 0.66206 |
| Mixed-01 | 0.01 | 0.1 | 0.09940 | 0.66004 |
| Mixed-1 | 0.1 | 0.1 | 0.09947 | 0.65274 |

Next-item-only выключает reward-часть и контролирует эффект дополнительных supervised-эпох. Hybrid reward - средний прогноз top-10, не ожидание полной softmax-политики.

Для отбора требовались NDCG >= 99% максимума reference/next-item-only, рост hybrid относительно reference/strong KL/next-item-only, ограничения охвата, концентрации и sampled-повторов. Никто не прошёл NDCG-порог; сохранён baseline. Seeds 43/44 по правилу не запускались: выполнено шесть обучений из максимальных десяти.

### Поведение и обучение

Выполнены 14 rollout на 1 000 validation-историй. Gamma 0.1 уменьшил sampled-повтор на шаге 5 с 25.2% у RL-only до 17.7%; уникальных объектов стало 4.281 вместо 4.024. Это улучшение синтетической генерации сопровождалось недостаточным NDCG.

## 2. Проверка на ранее не использованных пользователях

До обучения выбраны 1 000 пользователей Yambda с >= 50 train-прослушиваниями. Полная исходная популяция из 1 000 пользователей исключена; пересечение равно нулю. Выбор по ранней активности и фиксированному hash seed 20261015. Доли прослушивания при подготовке не читались.

Новая выборка: 5 000 запросов от 751 пользователя, 5 694 цели, прежний каталог 2 000 треков. Период `23121935 < T <= 26000000`; история BOS и последние 64 события строго раньше T. Target ID подготовлены заранее, но модели не оценивались на них до фиксации решения. Фактические доли присоединены после записи выбора и SHA checkpoint.

Смешанные модели на новый holdout не допущены. По плану оценены заранее заданные контроли. Новые пользователи неизвестны user-embedding reward model, используется прежний fallback без адаптации. Абсолютные метрики другой популяции нельзя сравнивать с прежним test как измерение прироста; ниже показано парное сравнение внутри новой выборки.

| Политика | NDCG@10 | Recall@10 | Hybrid reward |
|---|---:|---:|---:|
| Reference | 0.07980 | 0.12498 | 0.64150 |
| RL-only, beta 0.1 | 0.07849 | 0.12276 | **0.65792** |
| Strong KL, beta 1 | 0.08015 | 0.12583 | 0.64382 |
| Next-item-only | 0.07549 | 0.11809 | 0.64106 |
| Train-популярность | 0.01215 | 0.02429 | 0.64410 |
| Недавние + популярность | **0.10215** | **0.15727** | 0.64768 |

Strong KL повысил hybrid reward на 0.36%, NDCG - на 0.44% по точечной оценке. User-cluster 95%-интервал разницы NDCG [-0.000355; +0.001088] включает ноль; интервал hybrid [+0.002204; +0.002442]. Это описательное дополнительное сравнение. Основное подтверждение смешанного кандидата не проводилось, поскольку допустимого кандидата не было.

Next-item-only потерял 5.40% NDCG относительно reference; интервал разницы [-0.006885; -0.001771]. Контроль недавних треков выше reference на 28.00% по NDCG в этой популяции. Контроль недавних треков подтверждает резерв качества базовой политики.

### Ограничение reward на новых пользователях

Raw reward model MSE = 0.19637, global/user-mean fallback = 0.19368, hybrid = 0.19238. Pearson raw = 0.08187. Пользовательская средняя здесь совпадает с глобальной: все пользователи новые. Прогноз reward не объявляется откликом на произвольный показ. Сдвиг популяции и слабый сигнал кандидата ограничивают смысл оптимизации такого прокси.

Веса, коэффициенты, каталог и выбор по новому holdout не изменялись. Bootstrap: 2 000 повторов пользователей, seed 42, равный вес запросов. Интервалы контролей описательные, без коррекции множественных сравнений; неопределённость reward model ими не измеряется. Удовлетворённость и причинное удержание не оценены.

## 3. Воспроизведение и вывод

Новые данные: `data/processed/mixed-holdout-v1/`. Обучения, rollout, выбор и оценка: `outputs/mixed-objective-v1/`. Все новые артефакты отделены от первой серии; исходный test повторно не оценивался. Перед запуском следующей идеи понадобится новая ещё не использованная оценочная популяция.

```bash
python -m recsys_rl.mixed_experiment --device auto --prepare-only
python -m recsys_rl.mixed_experiment --device auto --resume
python -m recsys_rl.mixed_experiment --device auto --audit
```

Нужны локальные данные, reward-кэш и checkpoints первой серии с указанными хешами. Непустые каталоги не перезаписываются; `--resume` допускает только неизменный план. Для повторения текущего результата используется `--audit`. Подробности среды и предыдущих этапов - в [README](README.md).

| Этап | Полное время |
|---|---:|
| Подготовка новой популяции | 3.54 с |
| Шесть обучений, rollout и итоговая оценка | 164.50 с |
| Отдельный аудит | 41.38 с |

Apple M4/MPS, Python 3.14.7, PyTorch 2.14.1. Сумма внутреннего времени шести запусков - 108.64 с. Процесс серии: максимум RSS 1.53 ГиБ, peak memory footprint 2.76 ГиБ по macOS. Отдельный полный пик MPS/системы не измерялся.

Аудит повторил validation-forward шести сохранённых политик, все действия/reward 14 rollout, выбор, непересечение пользователей, присоединение новых response-меток, forward политик/reward и пересчёт метрик. Проверены хеши исходных моделей, кода и данных.

Опубликованы точные копии [результата серии](experiments/mixed-objective-result.json) и [нового holdout](experiments/mixed-objective-holdout-result.json), [подготовка](experiments/mixed-holdout-preparation.json), [ресурсы и аудит](experiments/mixed-objective-execution.json). История решения - в [журнале](История-исследования.md); первый [итоговый отчёт](Отчёт.md) сохраняет прежние результаты.

Next-item-only снизил train CE с 4.91443 до 4.02471, но validation CE вырос с 6.56984 до 6.67439, NDCG упал на 6.99%. Картина согласуется с переобучением/адаптацией к малому поднабору; причина не изолирована. CE рассчитан после серии и не управлял выбором.

**Вывод.** Проверенный рецепт смешивания уменьшил повторы относительно чистого RL, но не выполнил критерий релевантности. Новый смешанный checkpoint не принят. Контроль дополнительных supervised-эпох тоже ухудшился, поэтому проблема не сводится к отсутствию supervised loss. Общая бесполезность смешанного обучения этим экспериментом не доказана: проверены три gamma, один beta, пять эпох на 4 000 историях и один seed на этапе отбора.

Следующие обоснованные направления - усиление зависимого от кандидата reward-сигнала и включение явной давности прослушиваний в базовую политику. Они требуют отдельного протокола и независимой проверки.
