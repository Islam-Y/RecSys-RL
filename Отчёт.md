# RL для последовательных рекомендаций

## 1. Цель, данные и основной результат

Исследование второго задания T-Lab 2026: обучить GPT-2 предсказывать следующий трек, построить модель вознаграждения и проверить RL-дообучение. Продуктовая цель - полезные рекомендации и возвращение пользователя. Доступная метка - доля прослушивания; она служит косвенным сигналом и не измеряет удовлетворённость.

**Основной результат final test:** выбранный по validation вариант с KL = 0.1 повысил прогноз hybrid reward top-10 на **1.99%**, при снижении NDCG@10 на **2.55%** по точечной оценке. Интервал разницы NDCG включает ноль. Дополнительный вариант с KL = 1 дал меньший прирост reward (+0.28%) и близкие ranking-метрики. Рост пользовательского отклика не установлен.

Источник - [Yambda-50M](https://huggingface.co/datasets/yandex/yambda), 46 467 212 событий `listen`. Выбраны 1 000 пользователей по train-истории; каталог - 2 000 наиболее частых train-треков. История содержит BOS и последние 64 события строго раньше момента T; минимальная история - 5 событий.

| Выборка | Запросы | Пользователи | Цели | Покрытие событий каталогом |
|---|---:|---:|---:|---:|
| Train | 59 888 | 961 | 68 451 | 25.90% |
| Validation | 5 000 | 734 | 5 840 | 23.79% |
| Final test | 5 000 | 755 | 5 793 | 19.87% |

Глобальные временные границы: train до 19 983 235 секунд, validation до 23 121 935, test до 26 000 000. События с одинаковым user/T образуют множество целей и целиком исключаются из текущей истории. Каталог фиксируется по train. В test-контексте могут использоваться реальные события прошлых test-моментов; веса и коэффициенты по ним не обновляются.

Объекты вне каталога представлены токеном UNK: это 61.77% событий train-контекстов. Оценка условна на попадание цели в ограниченный каталог. Все 2 000 кандидатов ранжируются целиком; негативы не сэмплируются. Повторное прослушивание допустимо.

Recall@K - доля известных целей, попавших в первые K позиций. NDCG@K дополнительно учитывает позицию попадания. Каждому запросу присваивается одинаковый вес; K = 5, 10, 20. Главная ranking-метрика - NDCG@10.

## 2. Модели и обучающая цель

**Базовая модель.** GPT-2 со случайной инициализацией и собственными токенами ID: 2 слоя, ширина 128, 4 головы, 661 504 параметра. Сравнены три размера и восемь рецептов маленькой модели. Выбран learning rate 0.0001, dropout 0.1, weight decay 0.01; рецепт подтверждён seeds 42/43/44. Средний validation NDCG@10 вырос с 0.09026 до 0.10308 (+14.21%). Reference RL - seed 42, эпоха 26; лучший seed отдельно не выбирался.

**Reward model.** Отдельная embeddings/MLP-сеть, 202 593 параметра. Входы: пользователь, среднее и последний embedding истории, кандидат, взаимодействие history/candidate, длительность, повтор и доля UNK. Выход p - прогноз доли прослушивания. Метка - среднее `min(played_ratio_pct, 100)/100` по дубликатам `(user, T, item)`; нули сохраняются. Непрослушанным объектам нулевые метки не присваиваются.

Policy train разделён по времени: ранний reward train - 54 412 пар, selection - 14 039. Reward checkpoint выбран по selection MSE на эпохе 4. На selection подобраны калибровка и смесь с ранней персональной средней u:

`c = clip(0.7548164607*p + 0.1342643037, 0, 1)`

`hybrid = u + 0.4723990080*(c-u)`

| Прогноз | Validation MSE | Test MSE | Test MAE |
|---|---:|---:|---:|
| Общая средняя | 0.19457 | 0.19477 | 0.41451 |
| Средняя по треку | 0.19482 | 0.19709 | 0.40466 |
| Средняя по пользователю | 0.17407 | 0.17564 | **0.35590** |
| Исходная reward model | 0.17864 | 0.18133 | 0.36064 |
| Калиброванная | 0.17477 | 0.17693 | 0.37843 |
| Hybrid | **0.16932** | **0.17121** | 0.36546 |

Hybrid снизил test MSE относительно персональной средней на 2.53%, но повысил MAE на 2.69%. На test сравнение кандидатов одной истории: pair-weighted accuracy 59.08% [50.87%; 66.29%], 1 046 пар из 169 запросов; при равном весе запросов - 53.05%. Средняя по треку дала 62.48% и 55.96% соответственно. На validation accuracy модели была 51.65%, интервал включал 50%. Сигнал зависит от выборки и взвешивания; преимущество над трековой средней не установлено.

**RL-метод.** Модельный одношаговый контекстный бандит: `J = mean_h [sum_i pi(i|h)*r(h,i) - beta*KL(pi||pi_ref)]`. Полная сумма по каталогу даёт прямой градиент точного ожидания. Обучаются веса GPT-2; reward model и reference заморожены. Реальные переходы и многошаговый return не обучаются. Контрольный оптимум `pi_star = pi_ref*exp(r/beta)/Z(h)` используется для проверки; это не обучение DPO. [Rafailov et al., уравнения 3-4](https://arxiv.org/html/2305.18290v3#S4).

## 3. Validation: влияние reward и KL

Шесть вариантов начинают с одного reference checkpoint. Пять эпох на одинаковых 4 000 поздних policy train контекстах после границы reward train; response-метки не входят в loss. AdamW, learning rate 0.00005, batch 64, clip norm 1, weight decay 0; dropout выключен. Выбирается последняя эпоха. Бюджет и критерий записаны до запусков в [протоколе](experiments/rl-pilot-protocol.md).

Raw - p; hybrid - фиксированная смесь; time - `hybrid*min(duration,285)/285`. Reward в таблице - средний прогноз для top-10 с равными весами позиций, а не математическое ожидание полной softmax-политики.

| Политика, seed 42 | NDCG@10 | Recall@10 | Hybrid reward | Time reward |
|---|---:|---:|---:|---:|
| Исходная GPT-2 | 0.10275 | 0.15215 | 0.64978 | 0.42819 |
| Raw, без KL | 0.03920 | 0.06971 | 0.66923 | 0.38261 |
| Raw, KL = 0.1 | 0.09925 | 0.14735 | 0.66220 | 0.41035 |
| Raw, KL = 1 | 0.10271 | 0.15272 | 0.65148 | 0.42586 |
| Hybrid, KL = 0.03565745 | 0.09925 | 0.14735 | 0.66220 | 0.41035 |
| Time, KL = 0.1 | 0.09092 | 0.13606 | 0.64255 | 0.52933 |
| Time, KL = 1 | 0.10272 | 0.15217 | 0.64896 | 0.44001 |
| Недавние + популярность | **0.10776** | **0.16142** | 0.65543 | 0.43028 |

**Выбор.** Среди KL-вариантов требовались NDCG >= 95% reference и hybrid reward выше reference; выбирался максимальный hybrid. При равенстве - более ранний вариант. Raw-kl прошёл правило на seeds 42/43/44: NDCG 0.099247 / 0.098948 / 0.099273. Итог - seed 42, всего восемь обучений. Допуск 95% исследовательский, не продуктовый SLA. Дополнительные seeds меняли порядок батчей, сохраняя тот же reference.

**Коллапс без KL.** NDCG снизился на 61.85%; доля десяти самых выдаваемых треков выросла с 7.34% до 72.91%, охват упал с 93.85% до 16.30%. Энтропия полной политики снизилась с 5.692 до 0.504 нат при росте raw reward top-10 на 8.04%. Это измеренное расхождение прокси и релевантности; реальные отклики на изменённую выдачу неизвестны.

**Длительность.** Time с KL = 0.1 повысил собственный top-10 прокси на 23.62%, но NDCG снизился на 11.51%. Средняя длительность выросла с 191 до 246 секунд. Изменение reward меняет предпочтения по длине трека; психологическая польза такого сдвига не установлена.

**Контроль масштаба.** Hybrid имеет вид `0.3565745473*p + constant(user)`. При пропорциональном beta аналитические raw/hybrid вероятности совпали с погрешностью 1.48e-7. Обученные варианты дали одинаковый hybrid top-10. Калибровка улучшила регрессию, сохранив ранжирующий сигнал.

## 4. Итоговая оценка на final test

До открытия test зафиксированы [протокол](experiments/final-evaluation-protocol.md), код и хеши. Основное сравнение - выбранный raw-kl с KL = 0.1. Raw-strong-kl с KL = 1 заранее задан как дополнительное сравнение; по test победитель заново не выбирался. Нового обучения, настройки калибровки или перебора seeds не было.

| Политика | NDCG@5 | NDCG@10 | NDCG@20 | Recall@10 | Hybrid reward |
|---|---:|---:|---:|---:|---:|
| Исходная GPT-2 | 0.08012 | 0.09121 | 0.10319 | 0.14119 | 0.64693 |
| Raw, KL = 0.1 | 0.07511 | 0.08889 | 0.10035 | 0.14153 | **0.65979** |
| Raw, KL = 1 | 0.07981 | 0.09137 | 0.10319 | 0.14146 | 0.64871 |
| Train-популярность | 0.00777 | 0.01179 | 0.01792 | 0.02614 | 0.64904 |
| Недавние + популярность | **0.08695** | **0.10026** | **0.11223** | **0.15626** | 0.65237 |

**Основной результат:** raw-kl повысил hybrid reward на 1.99%, raw reward - на 5.37%; NDCG снизился на 2.55%, Recall@10 вырос на 0.24%. Разница NDCG = -0.002327, user-cluster 95%-интервал [-0.004946; +0.000226]; hybrid разница = +0.012861 [+0.012237; +0.013480]. Bootstrap: 2 000 повторов, 755 пользователей, равный вес запросов. Включение нуля не доказывает эквивалентность или отсутствие потери качества.

**Дополнительный результат:** KL = 1 дал hybrid +0.28%, NDCG +0.18% по точечной оценке. Интервал разницы NDCG [-0.000585; +0.000886] включает ноль. Это более осторожный компромисс в выполненном сравнении, без доказанного улучшения релевантности. Ни одна обученная политика не превзошла контроль недавних треков по next-item метрикам.

| Политика | Охват @10 | Концентрация top-10 объектов | Повторы истории | Длительность |
|---|---:|---:|---:|---:|
| Исходная GPT-2 | 94.20% | 7.03% | 26.14% | 190.60 с |
| Raw, KL = 0.1 | 89.25% | 8.90% | 25.30% | 177.64 с |
| Raw, KL = 1 | 94.25% | 7.29% | 26.34% | 188.94 с |

Полная softmax-политика raw-kl: expected raw reward 0.66809 -> 0.68906, hybrid 0.64547 -> 0.65294, KL = 0.09444. Эти величины отличаются от reward списка. Масса объектов с <= 10 ранними reward train парами выросла с 3.87% до 4.01%; сильного сдвига к малоизвестным объектам здесь не наблюдается.

На совпадениях top-10 с наблюдавшимися test-треками raw-kl: 822 пары из 5 793, средняя фактическая доля 0.65861; baseline: 823 пары, 0.65756. Наборы совпадений различаются. Это условная статистика, не оценка отклика всех рекомендаций и не причинный эффект RL.

## 5. Пять шагов и долгосрочная цель

Для baseline и шести seed-42 вариантов выполнены greedy/sampled-rollout: одинаковые 1 000 validation-историй, пять шагов, общие uniform-числа для сэмплирования. Выбранный ID добавляется как синтетическое прослушивание; сохраняются последние 64 события. Уникальность искусственно не навязывается.

| Политика и режим | Уникальных треков из 5 | Повтор предыдущего на шаге 5 | Raw reward: шаг 1 -> 5 |
|---|---:|---:|---:|
| Baseline, greedy | 1.027 | 99.9% | 0.69290 -> 0.72273 |
| Raw-kl, greedy | 1.017 | 100.0% | 0.72826 -> 0.75881 |
| Без KL, greedy | 1.003 | 100.0% | 0.77551 -> 0.81337 |
| Baseline, sampled | 4.253 | 16.6% | 0.67819 -> 0.68076 |
| Raw-kl, sampled | 4.024 | 25.2% | 0.69545 -> 0.71613 |
| Без KL, sampled | 1.169 | 96.2% | 0.77161 -> 0.80978 |

Greedy зацикливается уже у baseline: весь эффект нельзя приписать RL. Сэмплирование уменьшает повторы baseline, но не устраняет коллапс без KL. На пятом sampled-шаге десять наиболее выдаваемых треков занимают 6.2% выдачи baseline, 8.8% raw-kl и 98.2% без KL.

Добавление ID в историю сообщает модели о прослушивании, которого могло не быть. Рост reward по шагам относится к прогнозу на синтетическом контексте. Будущим действиям не присваивались вымышленные реальные метки или NDCG. Это диагностика переноса одношаговой цели на генерацию, а не оценка пяти реальных взаимодействий.

### Как приблизиться к удержанию

Сигналы для отдельного исследования: продолжение взаимодействий в пределах 30 минут и возвращение в интервале от 24 часов до 7 суток. Учитывать нужно события всего доступного каталога пользователя. Нулевая метка допустима только при полностью наблюдаемом временном окне; у правой границы данных пример цензурируется.

Офлайн можно проверить предсказуемость таких сигналов, калибровку, устойчивость по времени и пользователям, чувствительность политики к reward. Возвращаемость зависит от привычек, доступного времени и внешних факторов; корреляция с треком не устанавливает вклад рекомендации.

Для причинного эффекта нужны экспозиции и контролируемая проверка на пользователях. Проверять стоит возвращаемость вместе с негативными реакциями и явной оценкой рекомендаций. В текущем эксперименте модель удержания не обучалась; рост дослушивания или времени не приравнивается к удовлетворённости.

## 6. Ограничения, воспроизведение и вывод

- Каталог ограничен 2 000 треками, большая часть событий истории представлена UNK. Результат не переносится автоматически на полный Yambda или новых пользователей.
- Размеры, рецепты и checkpoints выбирались по одной validation. Final test открыт после фиксации настроек; после оценки выбор не менялся. Он отделён по времени, но относится к прежней популяции пользователей.
- Reward обучен на наблюдавшихся прослушиваниях; экспозиции и propensity исторической политики не восстановлены. Отклик на произвольный новый показ неизвестен.
- Проверен один reward checkpoint. Кластерные интервалы описывают вариацию по наблюдаемым пользователям, не неопределённость самой reward model; вторичные сравнения без поправки на множественные проверки.
- Обучающая задача одношаговая. Политика переходов пользователя и многошаговый return не моделировались. Удовлетворённость и причинное удержание не измерены.

Окружение: Python 3.14.7, PyTorch 2.14.1, Transformers 5.19.0, NumPy 2.5.4, DuckDB 1.5.6; Apple M4/MPS. Команды подготовки и обучения прошлых этапов - в [README](README.md). Требуются локальные данные и checkpoints, на которые ссылаются отчёты; `data/` и `outputs/` исключены из Git. Полные агрегированные метрики опубликованы.

```bash
python -m recsys_rl.final_evaluation --device auto
python -m recsys_rl.final_evaluation --device auto --audit
```

Final evaluation: 16.49 с, отдельный аудит: 14.13 с. Аудит повторно присоединил все test-метки из raw, пересчитал метрики/интервалы и воспроизвёл logits трёх политик и reward полного каталога с максимальной разницей 0. Веса и исходные данные сохранили хеши. Код final test: `c97ac8f0bf4656b24eeb74aa161f6b6c853d7594`.

Пилот восьми RL-обучений с rollout занял 177.83 с после кэша 14.81 с; максимум RSS процесса 1.56 ГиБ, peak memory footprint 2.74 ГиБ по macOS. Эти измерения не являются отдельным пиком MPS или всей системы. [Результат пилота](experiments/rl-pilot-result.json), [итоговый test](experiments/final-evaluation-result.json), [аудит и ресурсы](experiments/final-evaluation-execution.json), [журнал](История-исследования.md).

Методологические ориентиры: [GPTRec: beyond-accuracy и RL](https://arxiv.org/abs/2403.04875), [KL-цель и аналитический оптимум](https://arxiv.org/html/2305.18290v3#S4). Работа представляет собственный ограниченный эксперимент, не воспроизведение результатов этих статей.

**Вывод.** Заданный reward-прокси удалось повысить. Сила KL определяет цену в релевантности и концентрации; без KL возник коллапс. Сильный KL дал небольшой прирост прогноза при близких точечных ranking-метриках. Калибровка не создала нового порядка кандидатов, а синтетическая генерация выявила петли повторов. Оснований объявлять улучшение пользовательского опыта или удержания нет; содержательный результат - измеренный компромисс и проверенные границы метода.
