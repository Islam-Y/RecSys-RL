# RL с подтверждённым ранжирующим сигналом: протокол до запуска

15 октября 2026. Candidate-ranking-v1 прошёл заранее заданный confirmation gate: выбранный expanded CatBoost seed 42, 320 деревьев и фиксированная калибровка. Новый confirmation больше не используется для подбора. Исторические RL-результаты не меняются.

## Reference, reward и цель

Reference — исходная GPT-2 seed 42 плюс выбранная recency-смесь g = 0.1080394, tau = 16. Обучаются все веса копии GPT-2; g, q при фиксированном контексте, CatBoost и калибровка фиксированы. Политика `p_theta = (1-g)*softmax(logits_theta) + g*q_recent`. Без известных треков g = 0. KL считается между полными смесями p_theta и p_reference, а не между GPT-компонентами.

Reward — калиброванный прогноз доли выбранного CatBoost, по тем же 16 признакам и строго наблюдавшейся истории откликов. Priors до 12 000 000, learner до 16 809 665, калибровка на прежней reward-selection до 19 983 235. Calibration-период пересекается с поздними policy-train контекстами; калибровка имеет три параметра и фиксируется до RL. Validation/final метки в неё не входят.

Точное одношаговое ожидание: `L = mean_h[-sum_i p_theta(i|h)*(r(h,i)-lambda*I(i=last(h))) + beta*KL(p_theta||p_ref)]`. Last — непосредственно последний ID истории; при UNK/PAD/BOS штраф отсутствует. Знакомый трек, не соседний повтор, не штрафуется. Логарифмы ограничены снизу 1e-30 для численной устойчивости.

Четыре рецепта: beta 0.1/1 × lambda 0/0.1. Прежние 4 000 поздних policy-train контекстов/индексов, пять эпох, AdamW lr 0.00005, wd 0, batch 64, clip 1, dropout выключен. Последняя эпоха, без early stopping. Максимум шесть обучений: четыре seed 42 и seeds 43/44 выбранного рецепта. Дополнительные seeds меняют порядок батчей при одном reference, не обучение baseline заново.

## Оценка и выбор

Все 5 000 прежних адаптивных validation-запросов. NDCG/Recall 5/10/20, охват/концентрация/длительность, calibrated top-10 reward (равные веса позиций), expected reward полной смеси, KL/энтропия. Контроли: reference, recent-items, train-popularity, reference с жёстким исключением последнего ID; аналитические p_ref*exp((r-lambda*I)/beta)/Z для всех четырёх рецептов как диагностика одношагового оптимума. Аналитические/жёсткие правила не выбираются вместо обученной модели.

Допуск кандидата: validation NDCG >= 99% reference, reward top-10 строго выше reference, охват >= 95%, концентрация <= 125% reference. Дополнительно sampled rollout: повтор на пятом шаге не выше reference +1 п.п., среднее число уникальных не ниже reference −0.05. Среди допустимых максимум top-10 reward, равенство — порядок конфигурации. Выбранный рецепт подтверждается на seeds 43/44 с теми же проверками. При неудаче сохраняется reference, final reserve не открывается. Порог/бюджет не расширяются.

## Пять последовательных ID

Общие 1 000 validation-историй и uniform seed 42, greedy/sampled, пять шагов. GPT-2/recency получают синтетически добавленные ID и последние 64 события. Reward каждого сгенерированного трека оценивается относительно исходной наблюдавшейся истории откликов: она остаётся фиксированной на все пять шагов. Сгенерированный ID не получает played_ratio, не обновляет response-statistics и не объявляется фактическим прослушиванием. Это диагностическая генерация списка, не симуляция поведения пользователя и не многошаговое RL-обучение.

Hard-repeat control зануляет вероятность непосредственно последнего ID и нормирует остальные; сравнивается при том же режиме/случайных числах. Максимум 16 rollout: шесть seed-42 политик (четыре обученных, reference, hard control) × два режима плюс два режима для seeds 43/44 выбранного.

## Единственное открытие final reserve

Только после успешного development-подтверждения и записи SHA выбранных весов открывается ранее подготовленный reserve: 1 000 пользователей вне прежних 3 500, 5 000 ID-запросов. Новые training-пользователи также исключают reserve. Основное сравнение выбранной seed-42 RL со frozen recency reference. Дополнительно заранее фиксированы hard-repeat rule, recent-items и популярность. Другие RL-рецепты/seeds на reserve не оцениваются.

Основное подтверждение: нижняя граница парного 95% user-cluster интервала top-10 reward выше нуля И нижняя граница NDCG-разницы >= −1% reference NDCG. Bootstrap 2 000, seed 42, равные веса запросов. Reward model дополнительно оценивается на наблюдавшихся final-целях; совпадение рекомендации с наблюдавшимся треком не считается off-policy value. После открытия победитель и коэффициенты не меняются.

## Аудит и пределы

Код/план коммитятся до нового каталожного reward-кэша и обучения. Каталожные признаки сверяются с прямым history_features forward на всех 5 840 старых validation-целях (допуск 2e-6). Аудит повторяет reward и policy forwards, метрики/выбор, rollout-действия/reward, SHA и final join при открытии. Новые зависимости/автоматические тесты не добавляются. Рост прокси даже при лучшем ранжирующем сигнале не устанавливает удовлетворённости/удержания; reward подтверждён лишь на наблюдавшихся multi-target группах.
