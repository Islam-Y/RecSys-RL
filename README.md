# T-Lab 2026 — RecSys RL

Отдельный проект для второго задания отбора T-Lab 2026: последовательные рекомендации и дообучение модели с помощью обучения с подкреплением.

## Материалы

- [Условие задания](Задание.md)
- [Черновик решения и план экспериментов](Решение.md)

## Текущий статус

Зафиксирована постановка. Датасет, базовая модель, reward model, метод RL и протокол эксперимента ещё предстоит выбрать и проверить.

Основные этапы: обучить GPT-2-подобную модель next-item prediction, построить и оценить reward model, дообучить последовательную модель с RL и сравнить качество рекомендаций и поведение моделей. Все сравнения должны использовать временное разбиение без утечки будущих данных.
