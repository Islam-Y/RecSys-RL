# T-Lab 2026 - RecSys RL

Задание 2: GPT-2 для следующего трека, reward model, RL-дообучение и анализ поведения рекомендаций. Экспериментальная часть завершена 15 октября 2026.

**Результат:** подтверждены отдельные улучшения baseline, ранжирования наблюдавшихся кандидатов и sampled-генерации. Сохранение NDCG в допуске 1% при росте прогнозируемого reward не подтверждено. Пользовательская удовлетворённость и удержание не измерялись.

Строки относятся к разным оценочным группам. Каждый прирост сравнивает методы внутри своей группы; абсолютные метрики между сериями не являются последовательным ростом качества. Допуск 1% выбран нами, не задан Т-Банком. Положительный эффект RL по условию не обязателен.

## Заключительная проверка

Из Yambda-500M исключены все 10 000 raw user ID прежней 50M-версии. Основная группа: 5 000 выбранных ранне-активных пользователей, 50 000 запросов от 4 141. Дополнительная: 1 000 менее активных, 9 973 запроса от 701. Это тот же сервис и период, каталог 2 000 треков; покрытие основных test-прослушиваний 19.99%.

Правило top-100/alpha16/штраф0.1 применено без обучения и подбора: внутри shortlist сохраняется суммарная масса, снаружи вероятности reference неизменны. Это постобработка фиксированной политики, не новая RL-модель.

| Основная группа | Reference | Сохранение массы |
|---|---:|---:|
| NDCG@10 | 0.101423 | 0.100613 |
| Recall@10 | 0.157985 | 0.158084 |
| Прогнозируемый top-10 reward | 0.643694 | 0.661298 |
| Уникальных из пяти, sampled | 4.202 | 4.426 |
| Соседний повтор на шаге 5, sampled | 16.47% | 7.67% |

Парные user-cluster интервалы: уникальность +0.224 [+0.185; +0.267], повторы -8.80 п.п. [-10.18; -7.44]. По 1 000 общих контекстов/три sampling seed на группу. На дополнительной группе эффект также повторился.

NDCG-разница -0.000809, CI [-0.002043; +0.000336] хуже разрешённой нижней границы -0.001014. **Общий критерий не выполнен**: рост reward и generation-допуски пройдены, сохранение NDCG - нет. Это не доказательство потери более 1%; снижение также не установлено. Дополнительная группа не заменяет основную. Победа RL и причинный пользовательский эффект не заявляются.

Аудит воспроизвёл обе группы, 12 блоков расчёта, три policy и reward, все 24 запуска генерации и интервалы; максимальная разница forward 0. Оценка 242.43 с, аудит 203.61 с на Apple M4/MPS; peak memory footprint 2.84/3.08 GiB. Это время локальной оценки фиксированных моделей.

## Метод и запуск

- История: BOS и до 64 прошлых listen, все события текущего user/T исключены. Оценка полного ограниченного каталога, без искусственных негативных меток.
- GPT-2: 2 слоя, ширина 128, 4 головы, 661 504 параметра, случайная инициализация/ID-токены.
- RL: точное ожидаемое вознаграждение по каталогу с KL к reference; одношаговый контекстный бандит. Реальная многошаговая среда не обучалась.
- Reward: исходная MLP и поздний парный CatBoostRanker с калибровкой; история откликов строго до T.
- Генерация: синтетические ID добавляются policy; наблюдавшаяся response-история reward фиксирована.

Python 3.14.7; среда закреплена в [исходном lock](requirements-lock.txt) и [ranking lock](requirements-ranking-lock.txt). Для аудита последней серии нужны локальные входные артефакты; без них клон позволяет изучить код и агрегированные результаты.

```bash
source .venv/bin/activate
python -m recsys_rl.transfer_experiment --device auto --audit
```

Код вычисления последней серии `5081646`. Исторические аудиты требуют source commit своего этапа: новые Python-модули меняют общий снимок исходников. Подробные инструкции - в [воспроизведении](Воспроизведение.md). Новые параметры по заключительной оценке не подбираются.
