# T-Lab 2026 — RecSys RL

Второе задание отбора: генерация музыкальных рекомендаций и экспериментальная оценка reward-модели, ранжирования и RL-подхода. Исследовательская часть завершена 15 октября 2026 года.

## Результат

Сохранение вероятностной массы улучшило разнообразие sampled-генерации на новых пользователях. Общий критерий сохранения NDCG при росте reward не подтверждён; удовлетворённость и удержание не измерялись.

## Структура репозитория

```text
.
├── recsys_rl/        # Код подготовки данных, моделей и экспериментов
├── configs/          # Конфигурации запусков
├── experiments/      # Протоколы и агрегированные результаты
├── data/             # Локальные исходные и подготовленные данные
├── outputs/          # Локальные результаты запусков
├── requirements*.txt # Зависимости и версии для воспроизведения

├── Задание.md
├── Отчёт.md
├── Отчёт.pdf
├── Воспроизведение.md
└── История-исследования.md
```

`data/`, `outputs/`, `output/` и виртуальное окружение исключены из Git. Для аудита некоторых этапов также нужны локальные checkpoints. Подробности и ограничения приведены в отчёте.
