## Подтверждённые результаты

- GPT-2 с сигналом недавних прослушиваний улучшила NDCG на 23.73% и Recall на 26.55% относительно GPT-2; преимущество над контролем recent-items не установлено.
- Парный CatBoost лучше ранжировал наблюдавшиеся пары кандидатов: query-macro accuracy 58.42% против 53.52% у prior прошлых откликов на кандидата. Это не оценка CTR или NDCG.
- Сохранение вероятностной массы улучшило разнообразие sampled-выдачи на новых пользователях. На заключительной группе прогноз top-10 reward вырос на 2.73%, но NDCG снизился на 0.80% по точечной оценке; допуск 1% не подтверждён.

Эти эффекты получены на разных выборках и не складываются в единый прирост качества. Допуск 1% — наш критерий, не требование Т-Банка. Подробности заключительной проверки — в [отчёте серии](Проверка-переносимости.md).

## Метод и запуск аудита

- Контекст: BOS и до 64 прошлых listen-событий; события текущего user/T исключены. Метрики считаются по полному каталогу из 2 000 треков.
- GPT-2: случайная инициализация, 2 слоя, ширина 128, 4 головы, 661 504 параметра.
- RL: одношаговый контекстный бандит с KL к reference; реальные переходы пользователя не моделировались.
- Генерация пяти треков — синтетический rollout. Reward использует наблюдавшуюся историю откликов, а не вымышленные метки для сгенерированных треков.

Python 3.14.7; зависимости закреплены в [основном lock](requirements-lock.txt) и [ranking lock](requirements-ranking-lock.txt). Для аудита нужны локальные данные и checkpoints; они не входят в Git.

Команда аудита последней серии и исторические команды приведены в [инструкции воспроизведения](Воспроизведение.md). Для исторической проверки нужны source commit своего этапа и соответствующие артефакты. Новые параметры по открытой заключительной оценке не подбираются.

Исходники — в `recsys_rl/`, конфигурации — в `configs/`, протоколы и агрегированные JSON — в `experiments/`. `data/`, `.venv/`, `outputs/` и временные файлы исключены из Git. Raw, checkpoints и промежуточные прогнозы хранятся локально; код, агрегированные результаты и итоговый PDF опубликованы.
